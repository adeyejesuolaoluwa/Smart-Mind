# SmartMind

SmartMind is a responsive educational gaming website built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser. The website has no build step or package dependencies. Learning progress is stored in browser local storage.

## What is included

- Six interactive learning worlds and six playable, three-question missions.
- Explanatory answer feedback, mission progress, streaks, and achievements.
- A Premium page with example pricing and benefits.
- A checkout preview only: it does not collect payment details, charge users, or create subscriptions.
- A responsive interface and the supplied SmartMind logo.

## Premium preview notice

Premium prices and benefits are examples, not an offer for sale. A payment provider, account system, and production subscription features have not been connected.
