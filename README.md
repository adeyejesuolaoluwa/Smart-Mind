# SmartMind

SmartMind is a responsive educational gaming website built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser. The website has no build step or package dependencies. Learning progress is stored in browser local storage.

## Learning features

- Six interactive learning worlds and a growing catalog of short missions in mathematics, reading, science, geography, coding, budgeting, business, communication, and study skills.
- Multiple-choice, numeric-entry, step-ordering, and scenario questions, with optional hints and explanations.
- Subject pathways that group practice from introductory to more involved missions.
- A local learner profile with optional age range and subject interests to personalize mission suggestions.
- Mission history, achievements, and question-level skill-practice snapshots, including first-to-latest attempt comparisons.
- Responsive layouts, a skip link, visible keyboard focus, keyboard-operable controls, dialog focus management, live feedback, and reduced-motion support.
- A Premium page with example pricing and benefits.
- A checkout preview only: it does not collect payment details, charge users, or create subscriptions.
- The supplied SmartMind logo.

## Premium preview notice

Premium prices and benefits are examples, not an offer for sale. A payment provider, account system, and production subscription features have not been connected.

## Privacy and educational review

The learner profile and activity are stored in the browser's local storage; there are no accounts, server sync, or cloud backups. The profile does not request a birth date, school, or contact details. The optional age range does not currently filter or change lessons. Clear browser storage to remove locally saved profile and progress data.

Mission feedback and skill snapshots are practice aids, not formal assessments or proof of mastery. Content is a prototype and should be reviewed by educators for accuracy, age appropriateness, accessibility, and curriculum fit before classroom or child-directed use.

## Suggested manual checks

1. Save a learner name and a few interests; confirm mission suggestions change and the profile remains after refreshing.
2. Try a multiple-choice mission, a numeric-answer question, and the step-ordering question; inspect hints and answer explanations.
3. Finish and replay missions; confirm unique completion XP is awarded once while later attempts update skill practice and history.
4. Use each subject pathway and mission filter; verify matching missions appear.
5. Navigate with a keyboard, test the skip link and dialogs, zoom text, and enable reduced motion in the operating system.
6. Test with screen readers, learners, families, and educators before making educational or accessibility claims.
